# Sistem Rekap Absensi PPNU

Aplikasi web manajemen dan rekapitulasi absensi santri Pondok Pesantren Nurul Ummah (PPNU) Kotagede, Yogyakarta.

- **Kategori:** Asrama Putra (Subuh & Malam) dan MDNU Putra (Sore, Pel 1, Pel 2, Pel 3)
- **Tampilan:** Spreadsheet Matriks Mendatar & Mobile Responsive
- **Penyimpanan:** Dual-Storage Firebase Realtime Database & LocalStorage Cache
